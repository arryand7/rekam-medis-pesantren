# WF-DISCHARGE-001 — Discharge

## Outcome
- Kembali ke kelas.
- Kembali ke asrama.
- Istirahat dengan pembatasan.
- Kontrol kembali.
- Tindak lanjut khusus.

## Alur
1. Petugas menilai kunjungan dapat ditutup.
2. Catat kondisi akhir.
3. Catat instruksi.
4. Catat pembatasan aktivitas dan masa berlaku.
5. Tentukan penerima handover.
6. Kirim status operasional sesuai permission.
7. Finalisasi kunjungan.

## Guard
Kunjungan tidak dapat `discharged` bila observasi atau rujukan masih aktif.
