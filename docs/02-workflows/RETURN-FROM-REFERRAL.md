# WF-RETURN-001 — Kembali dari Rujukan

## Alur
1. Catat waktu kembali.
2. Unggah atau rangkum dokumen hasil rujukan.
3. Catat diagnosis/tindakan eksternal bila sah.
4. Catat obat dan instruksi lanjutan.
5. Tentukan observasi, kontrol, pembatasan aktivitas, atau discharge.
6. Informasikan pihak yang berwenang.
7. Tutup rujukan bila tindak lanjut telah jelas.

## Audit
Dokumen eksternal, perubahan instruksi, dan finalisasi rujukan diaudit.
