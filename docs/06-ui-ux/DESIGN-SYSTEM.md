# Design System

## Semantic tokens

- `background`
- `surface`
- `surface-muted`
- `foreground`
- `foreground-muted`
- `border`
- `primary`
- `success`
- `warning`
- `danger`
- `info`
- `focus-ring`

## Komponen inti

- App shell.
- Sidebar dan mobile navigation.
- Page header.
- Stat card.
- Status badge.
- Alert medis.
- Patient identity banner.
- Timeline.
- Form section.
- Data table.
- Empty state.
- Confirmation dialog.
- Audit drawer.
- Theme switcher.

## Status

Status harus memiliki label teks, ikon, dan warna. Jangan menggunakan warna sebagai satu-satunya pembeda.

## Spacing

Gunakan skala Tailwind konsisten. Form klinis memberi ruang cukup untuk pemindaian visual cepat.
