# Standar Tabel

- Pagination server-side.
- Search memiliki debounce.
- Filter dapat di-reset.
- Kolom sensitif disembunyikan sesuai permission.
- Header sticky untuk tabel panjang bila berguna.
- Mobile menggunakan card/list alternatif.
- Sort server-side untuk dataset besar.
- State filter tercermin di URL.
- Ekspor memerlukan authorization dan audit.
- Empty state menjelaskan tindakan berikutnya.
- Jangan menaruh terlalu banyak aksi dalam satu baris; gunakan menu yang jelas.
