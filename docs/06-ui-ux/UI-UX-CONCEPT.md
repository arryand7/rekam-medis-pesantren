# Konsep UI/UX

## Karakter

Tenang, klinis, cepat, jelas, dan tidak terasa seperti dashboard bisnis yang ramai.

## Prioritas

1. Keselamatan dan informasi kritis.
2. Kecepatan input.
3. Keterbacaan.
4. Kejelasan status.
5. Minimal klik.
6. Konsistensi mobile dan desktop.

## Workspace kunjungan

Satu halaman utama berisi:
- identitas dan warning,
- timeline,
- keluhan,
- vital,
- assessment,
- tindakan,
- obat,
- observasi/rujukan,
- disposisi.

## Dashboard

Menonjolkan:
- menunggu assessment,
- observasi aktif,
- rujukan aktif,
- kontrol hari ini,
- obat hampir habis/expired,
- handover shift.

## Larangan desain

- Warna berlebihan.
- Tabel tanpa prioritas.
- Informasi medis sensitif pada kartu dashboard umum.
- Modal bertingkat.
- Form panjang tanpa grouping.

## Identity banner

Workspace harus membedakan:
- identitas Gate;
- patient number;
- tipe pengguna;
- role akses pengguna yang sedang login.

Role admin pasien tidak boleh membingungkan petugas.

## Consultation composer

Gunakan preview ringkasan dan checkbox data yang akan dibagikan. Tampilkan tujuan, penerima, kanal, versi, dan warning red flag sebelum finalisasi.
