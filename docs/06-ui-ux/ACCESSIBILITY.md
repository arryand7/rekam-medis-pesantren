# Aksesibilitas

- Navigasi dapat digunakan dengan keyboard.
- Focus state terlihat.
- Form memiliki label terhubung.
- Ikon memiliki accessible name.
- Dialog mengelola focus.
- Toast penting dapat dibaca screen reader.
- Warna bukan satu-satunya indikator.
- Target sentuh cukup besar.
- Kontras diperiksa di light dan dark.
- Animasi menghormati `prefers-reduced-motion`.
- Tabel memiliki header semantik.
- Bahasa halaman ditetapkan `id`.
