# Standar Form

- Label selalu terlihat.
- Tanda wajib dijelaskan.
- Error muncul dekat field dan ringkasan di atas bila panjang.
- Data tidak hilang saat validation gagal.
- Auto-save hanya untuk draft yang aman.
- Tombol finalisasi berbeda jelas dari simpan draft.
- Aksi destruktif memerlukan alasan dan konfirmasi.
- Unit pengukuran tampil bersama input.
- Nilai vital memiliki validasi format dan konfirmasi outlier.
- Timestamp resmi tidak dapat diubah sembarangan.
- Keyboard mobile sesuai tipe input.
- Textarea medis mendukung karakter panjang tanpa terpotong.
- Tab order logis.
