# Operasional Sistem

- HTTP health.

## Runbook

- Queue gagal.
- Integrasi Gate gagal.
- Sinkronisasi santri gagal.
- Stok tidak konsisten.
- File gagal diakses.
- Restore.
- Security incident.
- User terkunci.
- Emergency downtime.
