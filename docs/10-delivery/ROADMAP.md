# Roadmap

## Phase 0 — Readiness
Validasi domain, bootstrap Laravel, CI, theme foundation.

## Phase 1 — Identity, Access, Audit
Authentication, role, permission, Policy, audit foundation.

## Phase 2 — Student Health Profile
Sync santri, profil kesehatan, alergi, kondisi penting.

## Phase 3 — Medical Visits
Registrasi, keluhan, vital, assessment, tindakan, lifecycle.

## Phase 4 — Observation
Monitoring, handover, outcome.

## Phase 5 — Pharmacy and Medication
Master, batch, stock, administration.

## Phase 6 — Referral and Discharge
Rujukan, hasil, instruksi akhir, status izin.

## Phase 7 — Reporting and Integrations
Dashboard, laporan, Gate/SSS/Absensi.

## Phase 8 — Hardening and Launch
Security, performance, UAT, backup, training, cutover.

## Phase 9 — Enhancement
Portal wali, notifikasi, outbreak, analytics, offline.

## Phase 1A — Gate Projection and Person/Patient Foundation
Kontrak Gate, sync dry-run/apply, person/user/patient, reconciliation.

## Phase 6A — Clinical Consultation
Summary, versioning, secure handoff, external advice, local decision.

## Phase 0A — Graphify
Install project-scoped skills, build documentation graph, readiness query set.
