# Release Checklist

- [ ] Scope release disetujui.
- [ ] Test lulus.
- [ ] Static analysis lulus.
- [ ] Build lulus.
- [ ] Migration direview.
- [ ] Backup tersedia.
- [ ] Rollback plan tersedia.
- [ ] Environment variable lengkap.
- [ ] Queue/scheduler dikonfigurasi.
- [ ] Permission storage benar.
- [ ] Security smoke test.
- [ ] Light/dark smoke test.
- [ ] Mobile smoke test.
- [ ] Audit event diuji.
- [ ] Dokumentasi diperbarui.
- [ ] Graphify diperbarui.
- [ ] Stakeholder diberi release note.
- [ ] Post-deploy monitoring dilakukan.
