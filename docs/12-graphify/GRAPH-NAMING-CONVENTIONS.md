# Konvensi Penamaan Graph

## Prefix dokumen

- `BR-` Business Rule
- `FR-` Functional Requirement
- `NFR-` Non-functional Requirement
- `US-` User Story
- `UC-` Use Case
- `WF-` Workflow
- `ROLE-` Role
- `ENT-` Entity
- `SCR-` Screen
- `AC-` Acceptance Criteria
- `TEST-` Test
- `ADR-` Decision
- `DOC-` Document

## Code

Gunakan nama eksplisit:
- `RegisterMedicalVisitAction`
- `MedicalVisitPolicy`
- `MedicalVisitRegistered`
- `RegisterMedicalVisitTest`

## Hubungan

Dokumentasikan kata:
- Implements
- Enforces
- Persists
- Emits
- Authorizes
- Displays
- Verifies
- IntegratesWith

- `SYNC-` Identity synchronization capability.
- `CONSULT-` Clinical consultation capability.
- `PERSON-` Human identity concept.
- `PATIENT-` Medical subject concept.
