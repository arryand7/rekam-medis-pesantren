# ADR-005 — Strategi Tema

## Status
Accepted.

## Decision
Mendukung `light`, `dark`, dan `system` dengan semantic design tokens. Default `system`.

## Persistence
Browser sebelum login, preferensi akun setelah login.

## Consequences
Setiap komponen harus diuji pada dua tema. Print dan dokumen tetap light.
