# User Stories

## Petugas kesehatan

- **US-001** Sebagai petugas, saya ingin menemukan santri dengan cepat agar kunjungan dapat segera dibuat.
- **US-002** Sebagai petugas, saya ingin melihat alergi sebelum memberi obat agar risiko dapat dikurangi.
- **US-003** Sebagai petugas, saya ingin mencatat assessment dan tindakan dalam satu workspace agar tidak berpindah banyak halaman.
- **US-004** Sebagai petugas shift berikutnya, saya ingin melihat handover observasi agar perawatan berlanjut.
- **US-005** Sebagai petugas berwenang, saya ingin membuat rujukan dengan ringkasan yang jelas.

## Pengasuh

- **US-006** Sebagai pengasuh, saya ingin mengetahui santri sedang berada di POSKESTREN tanpa melihat detail medis yang tidak diperlukan.
- **US-007** Sebagai pengasuh, saya ingin menerima instruksi istirahat atau kontrol.

## Wali kelas

- **US-008** Sebagai wali kelas, saya ingin mengetahui status izin belajar dan masa berlakunya.

## Manajemen

- **US-009** Sebagai manajemen, saya ingin melihat tren agregat agar dapat mengambil keputusan operasional.
- **US-010** Sebagai manajemen, saya ingin audit akses data sensitif bila terjadi insiden.

## Admin

- **US-011** Sebagai admin, saya ingin menyinkronkan identitas tanpa mengubah data medis.
- **US-012** Sebagai admin, saya ingin mengelola permission secara eksplisit.

## Pengguna umum

- **US-013** Sebagai pengguna, saya ingin tema mengikuti sistem atau pilihan saya.

## Gate dan patient identity

- **US-014** Sebagai admin, saya ingin preview sinkronisasi Gate agar konflik dapat diperiksa sebelum diterapkan.
- **US-015** Sebagai guru atau staf, saya ingin riwayat kesehatan tetap terhubung walaupun role atau jabatan saya berubah.
- **US-016** Sebagai petugas kesehatan yang juga admin, saya tetap dapat didaftarkan sebagai pasien.

## Konsultasi eksternal

- **US-017** Sebagai tim kesehatan, saya ingin membuat ringkasan kasus agar dapat meminta pertimbangan Puskesmas tanpa pasien langsung datang.
- **US-018** Sebagai petugas, saya ingin respons eksternal tercatat dengan jelas agar keputusan tindak lanjut dapat dipertanggungjawabkan.
- **US-019** Sebagai manajemen, saya ingin tahu data apa yang dikirim dan kepada siapa.
