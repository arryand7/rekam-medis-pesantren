# Glosarium

| Istilah | Arti |
|---|---|
| POSKESTREN | Pos Kesehatan Pesantren. Pusat penanganan awal santri sakit. |
| Santri | Murid yang tinggal di asrama. |
| Kunjungan | Satu episode pelayanan kesehatan sejak santri diterima sampai ditutup. |
| Keluhan utama | Masalah utama yang menyebabkan santri datang. |
| Tanda vital | Pengukuran seperti suhu, tekanan darah, nadi, laju napas, dan saturasi. |
| Assessment | Penilaian petugas berdasarkan keluhan, riwayat, pemeriksaan, dan data pendukung. |
| Tindakan awal | Penanganan pertama sesuai kewenangan petugas. |
| Disposisi | Keputusan lanjutan setelah assessment. |
| Observasi | Pemantauan santri di POSKESTREN dalam periode tertentu. |
| Rujukan | Pengalihan pelayanan ke fasilitas kesehatan eksternal. |
| Addendum | Catatan tambahan yang tidak menghapus catatan asli. |
| Audit trail | Jejak siapa melakukan apa, kapan, dari mana, dan apa yang berubah. |
| Gate | Aplikasi pusat identitas/SSO SABIRA. |
| SSS | Sistem sumber data santri yang kontraknya perlu dikonfirmasi. |
| State machine | Aturan transisi status suatu entitas. |
| PHI | Informasi kesehatan yang dapat dikaitkan dengan individu. |
| MVP | Versi minimum yang sudah memberikan nilai operasional utama. |

| Person | Representasi manusia yang identitas dasarnya berasal dari Gate. |
| User | Akun login yang dapat terhubung ke satu person. |
| Patient | Peran person sebagai subjek pelayanan dan rekam kesehatan. |
| Administrative account | Akun teknis/murni administratif yang tidak merepresentasikan pasien manusia. |
| Gate projection | Salinan lokal terkontrol dari data authoritative Gate. |
| Reconciliation | Proses membandingkan data lokal dan sumber untuk menemukan konflik. |
| Clinical consultation | Permintaan pertimbangan klinis profesional-ke-profesional. |
| Consultation summary | Ringkasan terstruktur yang dikirim kepada Puskesmas/rumah sakit. |
| External clinical advice | Respons yang diberikan tenaga kesehatan eksternal dan disimpan dengan atribusi. |
| Red flag | Temuan yang menurut SOP membutuhkan eskalasi segera dan tidak boleh ditunda oleh konsultasi jarak jauh. |
