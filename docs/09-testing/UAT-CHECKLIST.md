# UAT Checklist

## Persiapan
- [ ] Role pengguna UAT tersedia.
- [ ] Data sintetis tersedia.
- [ ] SOP yang diuji telah disetujui.
- [ ] Browser dan perangkat target tersedia.

## Workflow
- [ ] Registrasi kunjungan.
- [ ] Assessment.
- [ ] Observasi.
- [ ] Handover.
- [ ] Pemberian obat.
- [ ] Rujukan.
- [ ] Kembali dari rujukan.
- [ ] Discharge.
- [ ] Laporan.
- [ ] Audit.

## UX
- [ ] Ponsel.
- [ ] Desktop.
- [ ] Light.
- [ ] Dark.
- [ ] System.
- [ ] Keyboard.
- [ ] Pesan error.
- [ ] Loading/empty state.

## Keamanan
- [ ] Pengasuh tidak melihat diagnosis.
- [ ] Wali kelas hanya melihat status izin.
- [ ] Unauthorized direct URL ditolak.
- [ ] Export diaudit.

- [ ] Sinkronisasi Gate dry-run.
- [ ] Conflict reconciliation.
- [ ] Guru/staf sebagai pasien.
- [ ] User disabled dengan riwayat tetap.
- [ ] Membuat consultation summary.
- [ ] Preview data minimum.
- [ ] Mengirim melalui kanal uji.
- [ ] Mencatat external advice.
- [ ] Emergency referral tidak tertunda.
